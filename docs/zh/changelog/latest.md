## [v5.1.0](https://mp.weixin.qq.com/s/1IS91XFgCn4nBvs6M06V7g) (2026-09-05)

### 🐞 修复问题

- 修复键名/字段本地过滤时含斜杠路径搜不到（与 Redis MATCH 语义对齐）

## [v5.0.0](https://mp.weixin.qq.com/s/qtq9ESg-uYcR0tAyvDaCgA) (2026-08-28)

### ✨ 新增优化

- 新增 **Redis 安装帮助**
  - 填表生成 Linux Docker 部署产物，复制到目标机执行
  - 三种模式：单机 / 集群 / 哨兵
  - 可选 TLS：配套 openssl 自签证书脚本
  - 镜像可选 Redis、Valkey；支持密码、数据/配置外置、时区
- 终端: **命令键槽支持补全收藏键和已扫描键**，并优化提示的布局样式
- 连接: **RedisUrl 生成与粘贴解析** #152
  - 底部 URL 按钮一键复制当前连接串
  - 主机框粘贴完整 URL 或 host:port，自动填入主机、端口、账号密码、库号与 SSL
- 其他细节
  - db 未填时默认赋值 0 #153
  - CodeMirror 自动换行默认关闭
  - 升级前后端依赖到最新版本

### 🐞 修复问题

- 修复正式连接二次握手导致的偶发问题 #155
- 修复中英文切换时连接分组头行高跳动
