# 6.x 更新日志

## [v6.0.0 - 工作台](https://mp.weixin.qq.com/s/3PJszHk_5N-LWlCFDOYK7Q) <span class="changelog-date">2026-11-27</span>

### ✨ 新增优化

- 新增 **工作台**
  - 多行编辑命令，选中一段时只执行选中文字
  - 结果以标签保留；FT.SEARCH、CLIENT LIST 等可切成表格
  - 支持命令提示和执行历史；集群可选节点
- 页签: 按需显示，右侧「更多」里勾选，可恢复默认
- 配置: 支持 **写入配置文件** 和 对比集群 **各节点配置差异**
- 信息: 补上 **官网** 与 **原文** 入口
- 标题栏: 增加 **GitHub**、**检查更新**；发现新版本后可直接更新
- 其他细节
  - 终端输出格式默认改为 Raw，并排在首位
  - 运行配置的参考配置改到表格底栏，悬停选择版本
  - 集群下打开配置、客户端时默认看首个节点
  - 自动广播的说明写清开启、关闭时命令打到哪些节点
  - 英文页签名称改为 Terminal、Slowlog、Pub/Sub
  - 多处图标更新：页签、慢日志、断开连接、标题栏月亮、官网等
