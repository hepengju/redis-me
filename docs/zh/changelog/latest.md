# 5.x 更新日志

## [v5.5.0](https://mp.weixin.qq.com/s/bZYPBXn3KLDF0ex-Ox8aSQ) (2026-10-24)

### ✨ 新增优化

- 新增 **键空间通知** 标签页
  - 订阅 / 停止、通知参数与 pattern 编辑
  - 消息列表：关键词仅匹配键、事件列头筛选、flags 图例分组展示
  - 集群模式回显各主节点**配置一致性**，悬浮展示逐节点明细
- 终端: **拦截订阅阻塞类命令**；`SELECT` 同步切库；支持 Ctrl+V 快捷键粘贴
- 发布订阅: 消息内容支持**多行编辑弹框**
- 表格: 数据列**默认可排序**，表头点击支持三态取消排序
- 其他细节
  - 监控 / 发布订阅 / 通知: **批量缓冲** 缓解高频卡顿与1万行上限
  - 监控 / 发布订阅: 清空数据增加二次确认，去掉意义不大的操作列
  - 更新检查端点改用 release latest.json 并缩短超时
  - 升级前后端依赖（Vite+ 1.3.0、Tauri 2.12.4等）

### 🐞 修复问题

- 修复 macOS 终端右键粘贴权限报错（改用 Tauri 剪贴板插件）
- 修复集群建连在通告地址不可达时卡死（按配置超时兜底）
- 修复带列头筛选的列点击筛选时误触发排序

## [v5.4.0](https://mp.weixin.qq.com/s/h6S4mnUZvGLu85mztHzxBA) (2026-10-05)

### ✨ 新增优化

- 新增支持 **RedisSearch** 查询引擎
  - 基础功能：索引列表、新增索引、修改索引、删除索引
  - 查询功能：按查询条件检索数据，可选择是否显示分数
  - 浏览数据：点击键区切换为 Search 模式，并查询文档键
  - 索引信息：可查看原始信息与还原后的索引 DDL，字段详情显示类型标签和权重
  - 其他扩展：标签集合查看，同义词组可查看、新增和编辑，样例插入、文档跳转等
- 键区: 新增 Search 模式，**按索引全文检索**
- 键区: 工具栏可配置 **显示内存占用**
- 终端: **多行粘贴时提示**确认，作为单条命令或多条命令执行
- 解码: 新增 **Vector32**，Auto 可识别小端 FLOAT32 向量
- 官网: 新增 **实战手册**：慢日志专项治理、SSL 加密改造
- 其他细节
  - 查询框的精确勾选改到输入框左侧，占位符优化
  - 键列表的悬浮删除图标移动到右键菜单
  - 终端右键复制选中文本后提示成功
  - 代码区复制按钮改到右下角
  - 表格组件分页去掉跳转到第 N 页
  - 关闭连接改为后台释放，提升 UI 响应速度
  - 连接高级选项按钮改用提示，表单标签加宽
  - 空页深色主题恢复 Logo 光晕
  - 升级前后端依赖（Vite+ 1.0.0、Tauri 2.12）
  - 后端代码全量重构优化，并补充完善的测试

## [v5.2.0](https://mp.weixin.qq.com/s/oMVi3OsBLD-yaMfBbpxesA) (2026-09-10)
