# 5.x 更新日志

## [v5.8.0 - 键传输](https://mp.weixin.qq.com/s/BmdkRfVzEba5F22tGd9ZaQ) <span class="changelog-date">2026-11-14</span>

### ✨ 新增优化

- 新增 **跨连接键传输**
  - 顶栏菜单或当前连接入口；多选后可传输所选项
  - 支持 **原样复制** 或 **类型写入** 两种传输方式
- 键区: 菜单可 **显示 TTL**（剩余时间或永久），只查询当前可见键
- 键区: 勾选精确后，回车命中唯一键时 **直接打开**
- 信息: 改用 **INFO all**，可查看命令统计与延迟统计；分类下拉可输入筛选
- 目录内存分析: 结果可 **复制 / 导出**
- 其他细节
  - 收藏模式多选底栏与普通模式对齐（导出、传输、TTL、删除、取消收藏）
  - 批量菜单文案对齐为数据导出、数据导入、数据模拟
  - Linux 默认等宽字体补上 Noto Sans Mono / Ubuntu Mono
  - 只读代码区可选中、复制、搜索；信息与配置原文弹窗可查找，修改不写回
  - 目录右键「多选模式」放到「复制路径」前面
  - Linux 安装包桌面分类标为开发工具
  - 升级前后端依赖（Element Plus、Vue、Tauri 插件、russh 等）

### 🐞 修复问题

- 修复批量删除成功提示不显示实际条数 #178

## [v5.7.0 - Unix套接字](https://mp.weixin.qq.com/s/JoNqjj9Vb3KZZldBhwBMnQ) <span class="changelog-date">2026-11-07</span>

### ✨ 新增优化

- 连接: 支持 **Unix 套接字**
  - 本机直连（仅 Linux / macOS），或经 SSH 连接远端套接字（Windows 也可）
  - 粘贴 `unix://`、`redis+unix://` 自动切到套接字并填入路径
- Redis 安装帮助，官网安装工具同步对齐
  - 单机支持 Unix 套接字一键生成
  - 密码支持 **一键生成随机值**
- 设置: 更新检查可选来源 **自动 / Gitee / GitHub**
- 其他细节
  - 值区美化按钮样式优化；STRING 非文本编码时不显示
  - 连接首页**只保留分组模式**，顶栏连接下拉按分组顺序展示
  - 后端 redis 依赖改为 **redis-me-rs**（避免每次从 GitHub 拉取）
  - 官网截图更新，顶栏滚动后毛玻璃铺满；深色搜索框提亮等优化

### 🐞 修复问题

- 修复部分 Linux 环境(比如 Deepin25) WebKit DMA-BUF 导致的**启动白屏**
- 修复Fastjson等包含Set等集合时的非标准JSON字符串无法格式化的问题
