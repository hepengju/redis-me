## [v4.8.0 - 向量集](https://mp.weixin.qq.com/s/QxY6JSff7IEriojrYiNICA) <span class="changelog-date">2026-08-15</span>

### ✨ 新增优化

- 支持 Redis 8.x 的 **Vector Set 类型**
  - 基础浏览：元素 / 属性 / 向量三列展示，展示 VCARD 总数 / VDIM 维度
  - 双模式浏览：**随机采样**（VRANDMEMBER，默认）/ **范围查询**（VRANGE，游标分页续扫）
  - 增删改：VADD 添加 / VREM 删除 / 向量与属性编辑，元素名精确查询
  - 扩展: 新增 **VINFO** 元数据弹窗，整键（VRANGE 批量）/ 单行（VADD）
  - **VSIM 相似度查询**: 设置查询条件，>=0.85高亮显示，以此为种子查询等
- 命令日志：PIPELINE 聚合日志附带**首个命令**展示，二进制参数按 redis-cli 风格转义显示
- 其他细节
  - 字段默认扫描数调整为 20，降低首次打开大键的等待
  - 字段表格列名统一，Stream 查看字段增加 ID 显示
  - MeDialog 最大化 / 关闭图标统一，全屏布局对齐
  - 错误提示去除冗余前缀，直接展示服务端原始信息
  - Vue 组件注释分区、死代码清理与组件命名统一

### 🐞 修复问题

- 修复 Stream 字段查看 JSON 被误判为 Hex，改为按 UTF-8 展示

## [v4.4.0 - 字段扫描](https://mp.weixin.qq.com/s/O9uHI9wMX_cSoh3jBOkxzg) <span class="changelog-date">2026-07-18</span>
